## 0.9.0

First public release, built from source.

- **Apple Build: Build and Run** for a connected iPhone, My Mac, and iPhone Simulators, stopping at the first failed step.
- **Apple Build: Show App Console** records what the app prints after Build and Run, with errors and warnings first and the crash report added after a crash.
- **Apple Build: Show App Reports** lists the app's crash and resource reports in plain words, from the iPhone or from this Mac.
- Failed builds name the first Xcode error, and the build report starts with an **Errors** heading.
- **Apple Build Reader**, a native window with real VoiceOver headings, a Headings rotor, and Copy All (Command-Shift-C).
- Every list opens in a native chooser window that VoiceOver reads, instead of Nova's command palette.
- Build, Clean, and Test from the Extensions menu, plus Nova tasks with Reports and Issues.
- Read-only **Apple Signing Status** and **Apple Project Navigator** sidebars.
- Optional Mac voice announcements for people who do not use VoiceOver, both off by default.
